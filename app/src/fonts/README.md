# Fonts

The app's and the landing's fonts, loaded with `next/font/local` so a build needs no network.
Each file is the Latin subset Google Fonts serves, unmodified (what `next/font/google` used to
download at every build). Characters outside it fall back to the system font, as they did then.

| File | Font | Version | Licence |
| --- | --- | --- | --- |
| `inter-latin.woff2` | Inter, variable (weights 100–900) | 4.001 | `OFL-Inter.txt` |
| `ibm-plex-mono-400-latin.woff2` | IBM Plex Mono Regular | 2.3 | `OFL-IBMPlexMono.txt` |
| `marcellus-sc-400-latin.woff2` | Marcellus SC Regular (face II preview, landing only) | 1.001 | `OFL-MarcellusSC.txt` |

Licences from github.com/google/fonts (`ofl/<family>/OFL.txt`), read 2026-10-20.
